# DORA Metrics Analyzer - Frontend

This is the web interface for the **DORA Metrics Analyzer**, built with React and Vite. It provides a modern, minimalist, and dynamic user interface designed for a "WOW effect" to analyze the software delivery performance of GitHub repositories.

## Features

- **Real-time Streaming (SSE):** Watch the AI agent's thinking process in real-time.
- **Data Visualization:** Interactive charts built with `recharts`.
- **Enterprise PDF Export:** Download highly corporate, vectorized PDF reports of the generated analysis using `jspdf`.
- **Markdown Rendering:** Beautifully styled markdown responses generated by the AI agent.

## Getting Started

### Prerequisites

- Node.js 18 or higher
- The DORA Metrics Analyzer backend must be running.

### Installation

1. Navigate to the `frontend` directory:
   ```bash
   cd frontend
   ```
2. Install the dependencies:
   ```bash
   npm install
   ```

### Development

To start the development server with Hot Module Replacement (HMR):

```bash
npm run dev
```

The application will be available at `http://localhost:5173`. Ensure your backend is running at `http://localhost:8000`.

### Building for Production

To build the application for production:

```bash
npm run build
```

This will generate an optimized bundle in the `dist/` directory.

## Linting

To run ESLint and check for code quality:

```bash
npm run lint
```
